# Address Reuse

**Category:** Privacy

## Plain English

Using the same Bitcoin address for multiple transactions instead of generating a fresh one each time, which makes it easier for outside observers to link all of those transactions together.

## Analogy

Imagine using the exact same nickname every time you ordered food from any restaurant in town. Even without your real name, someone paying attention could piece together everywhere you've eaten and how often, just by tracking that one recognizable nickname across every receipt.

## In Context

*"Avoid address reuse, generate a new address for every transaction you receive."*

**What this means:** Instead of sharing the same Bitcoin address repeatedly, the person should use a fresh address for each incoming payment. Most modern wallets do this automatically.

## Why It Matters

Every transaction to a reused address gets permanently linked together on the public blockchain, making it much easier to see someone's total balance and full transaction history. Using a new address each time is one of the simplest habits for protecting privacy.
