# Tor

**Category:** Network

## Plain English

A free network that routes internet traffic through multiple layers of encryption and random relays, hiding where a connection actually comes from. Many Bitcoin nodes and wallets support connecting through it for added privacy.

## Analogy

Think of it like mailing a letter through several different post offices in different countries, each one repackaging it before sending it onward, so that by the time it arrives, nobody can trace it back to the original sender's address. Tor works similarly for internet traffic.

## In Context

*"I run my Bitcoin node over Tor to hide my IP address from the network."*

**What this means:** Instead of connecting directly to other Bitcoin nodes, this person's node routes its connections through the Tor network, making it much harder for anyone watching the network to link their IP address to specific transactions.

## Why It Matters

Without privacy protections, someone monitoring network traffic could potentially connect your IP address to the transactions you broadcast. Running Bitcoin over Tor is a common way privacy-conscious users reduce this exposure.
