# Mainnet

**Category:** Network

## Plain English

The real, live Bitcoin network where actual bitcoin with real value is sent, received, and secured, as opposed to test networks used for experimentation.

## Analogy

If testnet is the flight simulator, mainnet is the real airplane full of real passengers. Everything that happens here counts: real transactions, real money, real consequences if something goes wrong.

## In Context

*"Make sure your wallet is set to mainnet before sending real funds."*

**What this means:** The person is checking that the software is connected to the actual live Bitcoin network, not a test network, because sending real bitcoin to a testnet address (or vice versa) would result in permanently lost funds.

## Why It Matters

Confusing mainnet and testnet is a classic beginner mistake that can lead to real financial loss. Knowing the difference, and double-checking which one you're on, is a basic but important safety habit.
