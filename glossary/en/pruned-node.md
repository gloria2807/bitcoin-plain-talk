# Pruned Node

**Category:** Network

## Plain English

A full node that verifies the entire blockchain history but then deletes old block data it no longer needs, keeping only enough to continue validating new transactions, saving significant storage space.

## Analogy

Think of someone who reads every page of a huge stack of legal documents to make sure everything checks out, then shreds the older pages once they've confirmed everything is valid, keeping just a summary and the most recent pages on file. They still verified everything themselves; they just don't need to keep every page forever.

## In Context

*"I run a pruned node because I don't have enough disk space for the full blockchain."*

**What this means:** This person's node still downloads and validates every single block just like a regular full node, but afterward it discards old block data it doesn't need to keep around, keeping storage requirements much lower.

## Why It Matters

Pruned nodes let people with limited storage still fully validate Bitcoin's rules for themselves, rather than trusting someone else, without needing to store several hundred gigabytes of historical block data.
