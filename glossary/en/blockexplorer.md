# Block Explorer

**Category:** Network

## Plain English

A public website that lets anyone search and view every transaction, block, and wallet address on the Bitcoin blockchain. It's like a search engine for the entire history of Bitcoin.

## Analogy

Think of the blockchain as a public government record, every transaction ever recorded is printed there for anyone to read. A block explorer is the index that helps you search it. Instead of flipping through thousands of pages, you type in a transaction ID or a wallet address and it instantly shows you everything: when it happened, how much was sent, what fee was paid, and how many confirmations it has.

## In Context

I pasted the transaction ID into a block explorer and could see it was still unconfirmed.

After sending Bitcoin, you can copy your transaction ID (a long string of letters and numbers) and paste it into a block explorer like mempool.space or blockstream.info. It will show you exactly where your transaction is, whether it's still waiting in the mempool, how many blocks have confirmed it, and what fee was paid.

## Why It Matters

Block explorers make Bitcoin's transparency real and accessible. Anyone can verify any transaction without needing special software or technical knowledge. This is important for trust: you don't have to believe a sender that payment was made, you can just check it yourself. It also means Bitcoin has no hidden transactions; everything on-chain is visible to the entire world.
