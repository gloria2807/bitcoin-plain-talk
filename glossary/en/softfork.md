# Soft Fork

**Category:** Technology

## Plain English

An upgrade to Bitcoin's rules that is backwards-compatible, meaning older nodes can still participate in the network even if they haven't updated.

## Analogy

Imagine a market that used to accept both old and new naira notes. And then the government introduces a new rule saying: Only new notes are to be used for large purchases. People using only small notes can still buy small things, but over time, most people switch to the new notes because it works better. A soft fork works the same way: new rules are added, but nobody is forced off the network.

## In Context

SegWit was activated as a soft fork in 2017.

A new set of rules was added to Bitcoin without splitting the network or forcing everyone to update at the same time. Nodes that didn't upgrade could still send and receive transactions, they just couldn't use the new features.

## Why It Matters

Bitcoin upgrades itself through soft forks without breaking apart into separate coins. It's how the network improves over time while keeping everyone on the same chain. If the upgrade was not backwards-compatible, it would be called a hard fork and that can cause a permanent split.
