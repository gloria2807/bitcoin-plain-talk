# HD Wallet

**Category:** Technology

## Plain English

A "Hierarchical Deterministic" wallet that can generate a virtually unlimited number of Bitcoin addresses from a single seed phrase, instead of needing a separate backup for every address.

## Analogy

Imagine a master recipe that can produce endless unique variations of a dish, each one different but all traceable back to the same original recipe. An HD wallet works the same way: one seed phrase mathematically generates a whole tree of addresses and keys, so you only ever need to back up the seed, not each individual address.

## In Context

*"Most modern wallets are HD wallets, so one seed phrase backs up everything."*

**What this means:** If you're using an HD wallet, writing down your one seed phrase is enough to restore every address and key the wallet has ever created or will create, even if you generate a new receiving address for every transaction.

## Why It Matters

Before HD wallets, users had to back up every single address individually, an error-prone process where a missed backup could mean lost funds. HD wallets, standardized by BIP32 and BIP39, made backups simple and are now the standard across nearly all wallet software.
